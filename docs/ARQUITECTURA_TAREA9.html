1. Introducción

Este documento describe la arquitectura técnica del sistema de tienda online desarrollado como proyecto de la Tarea 9. El sistema permite la venta de productos (camisetas) mediante un catálogo público, carrito de compras como invitado, checkout transaccional y un panel administrativo para la gestión de productos, stock y pedidos.

La arquitectura sigue el patrón monolito modular con separación clara entre frontend y backend, priorizando simplicidad, rápida salida al mercado y facilidad de mantenimiento.

🎯 Objetivo
MVP funcional para venta online con catálogo, carrito, checkout y administración.
🏗️ Estilo
Monolito modular con separación Frontend / Backend / Base de Datos.
📱 Enfoque
Mobile-first, compra como invitado, panel admin protegido con JWT.

5. Modelo de Base de Datos

El sistema utiliza 14 tablas organizadas en 3 módulos principales:

5.1 Catálogo

TablaDescripción
categoriesCategorías de productos (slug único, soft delete)
productsProducto padre: nombre, slug, descripción, material, marca

user_rolesAsignación perfil ↔ rol

5.3 Operación Comercial

TablaDescripción

8. Seguridad

🔐 Autenticación
  • JWT con algoritmo HS256
  • Contraseñas hasheadas con bcrypt
  • Token expira a las 8 horas
  • Rutas admin protegidas con get_current_admin
🛡️ Validaciones
  • Precios recalculados en backend (nunca del frontend)
  • Stock validado atómicamente (sin negativos)
  • Payloads validados con Pydantic
  • CORS restringido a localhost:3000
  • Errores sin stack traces en producción

10. Conclusión

La arquitectura implementada cumple con los requisitos de un MVP funcional para comercio electrónico:

  • ✅ Separación clara entre zona pública y administrativa
  • ✅ Backend con validaciones transaccionales de stock y precio
  • ✅ Frontend mobile-first con componentes reutilizables
  • ✅ Persistencia en SQLite sin dependencia de servidores externos
  • ✅ Autenticación segura con JWT y contraseñas hasheadas
  • ✅ Trazabilidad completa de pedidos, pagos y stock
  • ✅ Preparado para evolucionar a PostgreSQL y pasarela de pago real

Tecnologías utilizadas: Next.js 16 FastAPI SQLite Tailwind CSS SQLAlchemy JWT
